# Mineshaft

**Status:** Early Overworld progression concept

## Progression Role

Main-line resource milestone associated with Iron and Coal progression.

## Build and Activation

The sketches suggest a stone-and-chain mine structure and a separate hanging track built
with wood and Chains. A lodestone or another anchor needs to be selected. Existing
implementation work has a small Mineshaft module; see the datapack README for its current
build specification.

## Rewards and Unlocks

Potential resources include Iron, Coal, Diamonds, Cobwebs, Rails, and possibly Mushrooms.
The hanging-track sketch proposes a Cave Spider Trial Spawner.
